# 当前包四岛连续实走

使用琥珀浅滩水陆声音更新后的本地包，SHA-256 为 `ebcd77b729c857a66bace0ecda7f3407624b0737c032c2abf08b972269c2f022`。从既有普通门廊存档导入，以原生键盘从潮汐海岸渡海去林地，和林栖交谈、采木、击败潮蟹，再渡海去雾岬登高和远舟交谈。经海岸转去琥珀浅滩拾贝并走到沙丘，最后回到原营火。为取得十分钟样本，在高地及营火周围走过重复路段。日夜按游戏时钟自然变化。

桌面和高 DPI 窄屏串行运行。使用签入的路线工具 `tools/run_settlement_forest_journey.mjs`，传入包名和 `--shoal`；`TIDELANDS_ROUTE_PROFILE=1`，`JOURNEY_WIDTH` 分别为 1920 和 390。计时探针附在独立解包的场景及主循环响应中。分段指标按检查点的存档时钟切分，便于定位较重路段。

## 桌面

1920 × 1080 绘制缓冲，实际显示 602.865 秒、36,109 帧，累计移动 3,243 米。木材 1→4、贝壳 0→2、击败 20→22，返营生命恢复到 100。主线第 6 步与原建筑保持，实际保存、刷新并从菜单导出完整状态一致。

完整四次绘制的 4,514 次 GPU 查询全部回收。GPU P95 为 18.575 ms，帧间隔 P95 为 24.1 ms，最大 83.9 ms。长于 50 ms 的 84 个间隔全部配对，其中 78 个主要耗时位于游戏回调之外，39 个出现在回营后的重复路段。最长停顿的前帧绘制只用 6.4 ms。另有一帧实际绘制用 75.9 ms，后续间隔 77.5 ms。浅滩登陆到沙丘段 GPU P95 为 22.865 ms，含 491 个显示帧。

导入附近还有一次 484 ms 的浏览器长动画帧，发生于上述持续计时的首个显示帧之前，浏览器将其中约 425 ms 记入游戏帧函数。已用 JS 堆在 84.4–132.1 MB 间波动，末次约 111.3 MB。计数覆盖浏览器内存和渲染资源驻留，实际显存与宿主调度的独立测量仍待完成。

## 高 DPI 窄屏

390 × 844 CSS 像素、DPR 1.5、585 × 1266 绘制缓冲，实际显示 602.415 秒、46,481 帧，累计移动 3,401 米。木材、贝壳、击败数和返营后的完整状态与桌面验收目标一致。5,810 次 GPU 查询全部回收，GPU P95 为 11.13 ms，帧间隔 P95 为 26.7 ms。

13 个超过 50 ms 的间隔主要耗时均在游戏回调之外，11 个出现在检查点前后 0.5 游戏秒内。最长间隔 128.5 ms，其中回调外占 123.9 ms，前帧绘制用 4.1 ms。导入附近、持续样本前另观察到一次 291.5 ms 的浏览器长动画帧。已用 JS 堆约 82.4–117.8 MB，末次 106.4 MB。

## 证据范围

两端无丢批、失效查询、隐藏帧、上下文丢失、GL 错误和控制台警告。相对角色的单帧镜头最大转动 3.76° 和 3.98°。与上次三岛路线相比，本次增加了浅滩往返，帧时分布直接记录为当前包基线。桌面浅滩段 GPU P95 超过 60 Hz 的单帧时间，启动附近的长帧也有待定位。当前运行包保持同一校验值。
