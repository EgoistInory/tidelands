# 区域岩体与林下层次候选

承接已拒用的地表噪声实验，空间体量才是主要差距。本组选择既有全部石料节点的区域组合岩体，以及既有林下植被群落的疏密高低；不重复树叶资产或调色。各区域岩体保持原2.8米石料碰撞包络与3.5米相机障碍高度，资源位置/身份/数量、地形、可采集性与材质保持；林下植物仅改Y比例，原根部和XZ占地保持。采用已有岩面几何与PBR，不增加贴图/外部资产或付费调用。

先隔离比较海岸/林地/高地/浅滩四对同位原生画面，再390夜营与180帧移动；检查包络与全部节点不变。若整场轮廓改善且未超预算，再接生产并验证采集/移动/相机与独立交付；若不改善，一次拒用后收口，不继续磨单岩块。候选不是普通主线或最终品质证据。
