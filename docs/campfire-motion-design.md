# M5 营火可见运动的有限批次

实际夜营画面中营火仍是两枚不动的发光锥体。此次只替换营火火焰表现：三张交叉薄片合为一个网格，以无贴图的程序噪声形成向上流动、边缘透明、底部明亮的火舌。共用生产世界时间，暂停冻结，多个营火独立相位；原石圈、木材、近处光源、规则和存档保持。

选择小型 ShaderMaterial：不增加下载、纹理或粒子常驻资源，保持一次火焰 draw call，现有 mesh 清理和建造预览材料替换可以继续使用。相较单纯缩放锥体，透明的变化轮廓直接解决静态实体感；此次不引入流体、烟雾或后处理。

验证：先证明新网格/独立时间与重复预览清理的规则失败，再接入；在生产 WorldView 的隔离营地看昼夜/四个方向、冻结和 10 秒运动，保存实际截图与帧/程序/几何计数。无存档读写。最后独立打包和普通新档保存刷新检查。此批次不代表整体美术、物理火焰、自然动作、GPU/真机或完整 M5/3A 验收。
