# 四岛地表尺度候选审查：保留隔离，不接生产

实际生产画面仍有均匀草坡与裸露高地。此次开发并运行了一个材质尺度候选：草纹双方向/比例采样去重复、约20米连续干湿斑、岩层噪声边界。全部位于tests，不改地形、资源、植被布局、生产材质、普通存档或现有交付。

`ground-breakup-browser.json`和11张已查看的原生JPEG记录四岛正午同位旧新、390午夜营地同位旧新及林地180帧移动。五对位置、相机、时间、天气、缓冲、draw calls/三角/纹理数量逐项相同，GL0、console空。隔离页的“生产原地表”使用同一实验shader且amount=0，数值上保留原表达式；不把它当原始生产shader成本基线。切换控件、真实WorldView/movePlayer/tick执行；不是普通main/全主线路径或物理手机。

视觉判断：林地增加少量干草色块，高地纹理边界更强；海岸/浅滩主要沙地几乎不变。大片光滑坡面、裸山轮廓与树草分布没有改变，夜营也没有主要层次提升。因此不接生产，不继续调整噪声强度/单色参数。数学去重复不是美术质量通过；额外采样/噪声的GPU成本未测，不应为有限收益增加生产着色器负担。

有效视口分别1280×720与390×844，页面保留QA栏：实际完整canvas桌面1280×598、缓冲1920×897；竖屏canvas390×684.5、缓冲390×685。没有将工具栏占用的高度称为全视口游戏画面。林地移动180帧、21.000000000000725米，rAF P95 16.8/max18.3ms，无hidden/GL错误；只有约3秒声明移动，不是GPU/长时/完整路径证据。
