# 当前包的连续跨岛实走

在 `5d10d6f2` 包用旧的普通门廊进度继续。原生键盘从海岸渡海到林栖、采木、击败潮蟹，再渡海到雾岬登高与远舟交谈。为取得十分钟的连续样本，在高地往返后返回原营火休息。全程经历夜晚、清晨、午后和黄昏，未修改游戏时钟。最后木材 1 → 4、击败 20 → 21、生命 100 → 86 → 100，主线第 6 步与原营火保持。保存、刷新再导出，完整规范化 JSON 一致。

## 桌面持续采样

1920 × 1080 绘制缓冲实际连续显示 601.879 秒，38,733 帧，其中 27,937 帧收到移动输入，878 帧位于地形海拔低于零的位置。样本包含为延长采样而重复走过的高地和营地道路。

| 指标 | 中位 | P95 | 最大 |
| --- | ---: | ---: | ---: |
| 完整四次绘制 GPU 查询（4,842 次） | 14.55 ms | 18.80 ms | 37.80 ms |
| 帧间隔 | 15.80 ms | 26.50 ms | 77.70 ms |
| CPU 世界绘制提交 | 4.80 ms | 6.10 ms | 58.90 ms |

查询全部释放，无丢批、隐藏帧、上下文丢失、GL 错误和控制台错误。相对镜头最大单帧转动 3.98°。浏览器记录的已用 JS 堆为 83.9–127.3 MB，结束约 88.4 MB。资源计数包含跨岛首次驻留，不能由此推断显存或证明无泄漏。

大于 50 ms 的帧间隔共有 59 个。最长的 77.7 ms 出现在林地登陆后，前一帧 CPU 世界绘制 5.9 ms。浏览器当时记录游戏帧脚本约 6.3 ms。另有个别明显的绘制提交尖峰。当前证据能保留两类观察，尚不能将回调之外的时间归到某个渲染模块。

## 采样开销与剩余长帧

长跑的分段探针以浏览器传入的帧时间触发，只能配对 17 个长帧。将触发改为实际绘制开始时间后，用原包重走林地至营火的短路线，能配对桌面全部 6 个长帧。其中 3 次紧随同步 GL 状态检查，探针外层比实际世界绘制多用 34.6–43.9 ms。

新版探针把 GL 错误检查移到计时结束后，并将周期快照中的未检查值记为 `null`。相同包的第二轮短跑再次走到营火，并通过存档导出与恢复检查。

| 1920 × 1080 | 3,064 | 19.57 ms | 23.3 ms | 60.6 ms | 4 |

桌面剩余 4 次均成功配对。3 次的前帧真实绘制耗时 50.5–59.5 ms，另一次的 60.6 ms 间隔有 53.2 ms 位于游戏回调之外。两端结束时 GL 错误为 0。本轮没有变更游戏渲染代码。短跑可辨认测量开销和实际长帧，但单组时序无法归因回调外停顿或推算十分钟长跑的修正计数。
