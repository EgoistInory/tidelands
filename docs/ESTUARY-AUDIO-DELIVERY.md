# 苍翠林地渡口的动作与声音

浅水段原本一过地面零高度就按游泳距离播放水声。这时正式角色还在走路。现在声音读取实际渲染姿态，浅水只在落脚时播放短水花，转入游泳后重新累积划水音效的移动距离。游泳仍使用距离节奏，手入水的逐帧同步留待动作审查。

潮滩碎石、裸岩和林下落叶共用渡口地表的分布数据。风声随岸线高度渐变，背风林地再降低风量和高频。脚步、涉水与环境声复用现有合成声音和声部上限。新 ZIP 比渡口地貌包增加 620 字节。
