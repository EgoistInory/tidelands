# 角色与营地织物材质批次

当前外套、裤子、围巾、背包和帐篷布使用单色标准材质，近景缺少同一材质语言。此批只补充共享织纹与细微表面起伏，保持既有颜色、角色轮廓、关节、玩法及存档。

使用两张本地确定性 128×128 DataTexture：sRGB 灰白织纹调制原颜色、线性高度图形成浅凹凸。纹理重复、生成 mipmap，所有角色/NPC和营地布面共用，避免每个角色生成贴图。只在明确布料部件使用，皮肤、头发、皮靴、金属与木材继续原材质。帐篷每块布按局部平面投影生成以米为单位的UV，防止不同大小面板随意拉伸。

验证输出纹理通道/重复边界/共享、皮肤隔离和UV；保留既有落脚/动作回归。隔离生产场景按同镜头开关织物，与近景角色、帐篷和昼夜/390尺寸检查；开关的关闭态是QA模拟单色基线，不能冒充完整旧版渲染。查看实际JPEG和运动，检查GL/控制台，再独立解压普通开始/保存/恢复交付。

此批不能解决脸部/植被轮廓、坡面物体接地、所有穿插或完整自然动作，也不证明3A、GPU预算或最终质量。有限收口后继续下一整体品质工作，不反复单个布面打磨。无外部素材、付费服务、新依赖或公网发布。
