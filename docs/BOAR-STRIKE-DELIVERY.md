# 野猪蓄力和扑击

原来野猪在前摇期间已向前挺身，实际触发伤害时吻部反而上扬并略向后缩。现在先沉肩、后移重心，再沿锁定方向向前顶撞，随后收回。蓄力、撞击和收势复用原有游戏时钟及四足着地解算。攻击判定继续使用既有射程与 .30 秒的命中时刻。

## 浅滩实际遭遇

桌面、窄屏分别在旧包和新包导入同一普通遭遇档，以原生输入经历野猪和潮蟹出招、反击和食用恢复。对第一次野猪攻击在真实地形记录吻部沿身体朝向距根节点的距离。每个窗口均在相同世界落点取得蓄力与命中附近的帧。

| 窗口 | 旧版蓄力 → 命中附近 | 新版蓄力 → 命中附近 | 新版两时点着地蹄数 |
| --- | ---: | ---: | ---: |
| 1280 × 800 | 1.83 → 1.80 m | 1.69 → 2.20 m | 3 / 3 |

距离取自原生画面对应的模型点，地形与攻击时机随实游推进。两端击败数 3→4，前摇弧线与敌人栏一致，暂停、刷新与完整导出通过。控制台和 WebGL 无错误。新旧两端的原始录像、输入、逐帧数据与导出副本留在本机 `dist/boar-strike-baseline-r1` 和 `dist/boar-strike-native-r1`。[旧版实游记录](boar-strike-2026-11-23/baseline.json) · [新版实游记录](boar-strike-2026-11-23/native.json) · [窄屏受击画面](boar-strike-2026-11-23/narrow-contact.jpg)

固定坡面的回归在旧版因蓄力未后移下沉而失败。新版通过逐帧连续性、触地间隙、前伸以及回到静止位的校验。当前野猪近景的材质与轮廓精细程度仍是整体质量待办。
