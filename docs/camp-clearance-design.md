# 营地与植被衔接批次

上一织物批次的390帐篷图实际可见草叶穿入地板。草/花/密草/沙草/蕨丛都是静态实例；只做镜头区域剔除，没有动态建筑占地避让。建筑最多可导入500个，不能用少量shader uniform只覆盖前几个。

此批在WorldView.sync的建筑增删、位置或类型变化时，按建筑已有固定方向的保守占地范围，隐藏与占地相交的完整草丛实例。保存仅被隐藏实例的原矩阵；换档移除/挪动建筑时恢复，原边界维持，以便恢复后剔除正确。未变化的建筑签名直接跳过，不在每帧扫描所有实例。不改植被原始生成/随机序列、资源节点、地形、建筑/背包/存档规则，不增加纹理、shader或依赖。

验证顺序：实例恢复/同数换档/重叠/500个建筑尾项/静态边界与缓存回归；实际营地GL开关与桌面/390画面；生产建造/保存或导入路径接线；独立本地包普通流程，冻结上一textile包及旧审计。清理整簇会在建筑边沿形成保守净空，并非割草或草叶物理碰撞；建筑在坡面接地、玩家角色/植被细节、试听和最终长时设备/GPU品质继续待办，M5/3A不因这批勾选完成。
