# 下一材质批次：岸线砂砾的三通道表面

湿沙批次已形成明暗和粗糙度带，但岸线仍沿用程序噪声凹凸。下一步用本地沙粒漫反射、OpenGL法线和粗糙度，在既有地域颜色上补充真实细粒层次。先做这个有明确画面差距的批次，再处理天气与整体材质协调。

已核对 [Sand 03 官方页](https://polyhaven.com/a/sand_03)：作者 Charlotte Baglioni，覆盖宽度2米。该资产使用 [CC0](https://polyhaven.com/license)；[官方 API 文档](https://polyhaven.com/our-api)及[服务条款](https://github.com/Poly-Haven/Public-API/blob/master/ToS.md)确认默认接口免费，开发时请求带项目 User-Agent。三张1k JPG共1,879,056字节，官方大小/MD5、本地SHA和1024×1024解码已核对；见 coastal-sand-preparation.json。暂放 docs/material-preparation/sand03，未接入运行时、未纳入协调动作包。贴图本身已查看，不能代替游戏实景验收。

保持当前 terrain、顶点地域颜色、对象ID和存档；草地与沙地加载/失败独立，任一组失败保留另一组和原程序地表，湿润带继续独立工作。沙地从水线上渐入，在2.5–5.5米与草地交接，陡岩及深海底保持。根据实际采样校准沙粒亮度/强度，避免原棕色整片覆盖地域色调；湿润带的最终粗糙度仍由既有逻辑控制。

复用2米的世界坐标投影、Repeat/mipmap和最多4倍各向异性；仅新增三个采样器，不增地形网格或绘制次数。添加明确的沙地开关供隔离对照。先验证草/沙两组成功与分别失败、法线/粗糙度边界，再取得四岛同位/高岸/陡岩/深海底、昼夜和390窄屏的实际WebGL及画面。记录多三张纹理的真实资源和当前动态/冷场影响，不能继承旧包长时结论。
