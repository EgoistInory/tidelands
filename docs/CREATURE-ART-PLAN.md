# 生物整体造型与表面批次

目前生产野猪由两个相互重叠的躯干/头部旋转面组成，蟹壳和两类皮面仅用平涂材料。既有八腿/四腿接地与攻击关节、AI/存档/伤害、每物种几何缓存均已存在。新人物和本地地表已有纹理后，生物的平涂玩具感成为明显风格断层。本批同时处理两类生物的整体表面，野猪改连通的肩背到吻部轮廓，蟹增加壳缘起伏和不对称螯；不另调单眼或单蹄。

采用本地确定性生成的小幅皮毛/壳斑颜色、法线和粗糙度，无远程素材、付费API或依赖。每物种每WorldView最多三张共享128纹理，受击材料仍逐生物私有，最后一只释放时清理纹理。保留全部腿关节与脚端、攻击时序、身体朝向、AI/碰撞/存档，近远轮廓一致。生成表面不是作者原画或最终3A证明。

1. 三项 RED 已实际失败：两个物种没有纹理，野猪没有跨越后躯到吻部的连通皮面。
2. 精确改造材质/连续躯干和壳缘，绑定既有生命周期；不增加全局常驻资源。
3. 核对共享/释放与动作规则，实际同源全身及生产战斗、桌面和390呈现；保留自然度/接地/纹理重复的缺口。
4. 有限组通过才收口；当前夜间包a0fd4fa6与普通备份保持，新源性能/包/最终证据不得套旧SHA。
