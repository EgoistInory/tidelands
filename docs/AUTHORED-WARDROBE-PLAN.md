# 连续骨架人物衣装候选

按既有整组角色方向继续，不扩玩法。当前生产人物仍有原型感；本批在已取得的CC0连续人体上完成旅人、守灯人、药草师、航海家四种衣装及真实头骨绑定发型，先隔离审查再接生产。原基础人体保持，遮住衣服下皮肤；衣物沿同一65骨骼变形，背包/围巾挂真实spine_03，头发挂真实Head。不把裸人体或换色皮肤当完成。

衣装采用贴体袖裤与有体积的长马甲、腰带、靴身、皮革包/身份装备；沿原模型权重重用或采样转移，不另造骨架。四身份采用赭色旅行衣/床卷、灯守金褐外衣/灯袋、草绿衣/药袋、蓝灰衣/航海卷。肤色与面部原图保留，衣物用已有织物材质。先验证骨架/原数据不变、头手露肤/其余覆盖、配件随骨运动、四身份桌面与390动作视图。该候选不立即替换生产，不宣称地形IK、装备命中时序、泳姿或M5已验收；后续同一模型完成游戏动作适配再统一替换和交付。

独立验证流：本地候选页 → 选择四身份 → 待机/步行/冲刺/采集/挥剑/泳姿 → 全身及侧后面、390画面。保存实际图与有限帧证据，明确穿插/滑步等遗留，不反复打磨单袖口。原普通档和ZIP保持。
