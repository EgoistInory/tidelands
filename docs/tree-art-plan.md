# 树木整体轮廓批次

本轮依据当前character包与真实林地/出生树林图继续M5：细叶/树皮贴图已存在，但笔直圆筒主干、短粗悬枝和同一高度的叶团仍有程序化感。沿用户已授权的无人值守品质方向，先使根颈、收细主干、主枝/细枝与树冠形成连续轮廓，再检查树林整体；不改变节点位置/数量/采木、碰撞、存档或增加采购/API。

选用已有共享树皮和叶片/影子材质，用弯曲根颈与渐细枝组、对应七冠簇代替直杆和五独立短枝。保留两种实例化表面、原叶片数量和风动资源；在合并前分别计算主干/各高枝/树冠镜头包围盒。资源变化/几何预算与旧character包比较，运行相关几何/镜头/耗尽恢复回归，实际正侧/枝干近景/树林昼夜/390审查与当前动态样本，再独立解压普通采木保存恢复。非阻断的同形树种、坡地根部接地/光照等留为品质待办，继续声场试听和当前完整普通流程，不能把这一树模型升级作为M5或3A完成。
