# 路线帧预算与林木首次出现

从两份真实历史存档出发，分别走完林地黄昏、渡海与夜间返营，以及雾岬高地下山再登高。用 1920 × 1080 和 585 × 1266 两种实际绘制缓冲比较新旧本地包。GPU 查询覆盖完整场景和三次后期绘制，CPU 提交与帧间隔分开记录。

## 首次进入林木近景

两端接近 `resource-7` 的 12 米近景阈值时，旧版第一次画细节模型，同段增加 3 份几何、9 张纹理与 2 个着色程序。最长帧分别为 129.2 和 91.6 ms，前次 CPU 绘制占 127.5 和 89.4 ms。

加载界面关闭前，新版通过现有 HDR 目标离屏绘制一次共享林木近景。使用既有灯光和模型，恢复实际镜头、剔除及可见性。两端到达同一阈值时没有再新增模型几何或纹理。

| 范围 | 1920 × 1080，旧 → 新 | 585 × 1266，旧 → 新 |
| --- | --- | --- |
| 进入林木近景前 4 帧至后 6 帧的最大帧间隔 | 129.2 → 40.0 ms | 91.6 → 20.7 ms |
| 林地返营全段，GPU P95 | 20.51 → 19.80 ms | 11.75 → 12.59 ms |
| 林地返营全段，帧间隔 P95 | 25.2 → 24.9 ms | 26.7 → 26.7 ms |
| 高地下山、登高全段，GPU P95 | 18.18 → 15.78 ms | 9.29 → 9.31 ms |

4 次离屏预热绘制耗时 58.3–470.5 ms，提前建立 3 份几何与 12 个纹理对象，其中包括渲染目标。该数值是离屏调用耗时，未测量加载总时长差或物理显存。桌面新版返营还有 7 帧超过 50 ms，最慢 58.7 ms。该最慢帧的前次绘制仅 6.4 ms，且该帧附近没有 GPU 查询结果，原因待查。动态路线的实际动作、端点和时刻存在小差异，P95 变化仅作本次现场观察。

## 验收与复现

八次实跑均使用实际文件选择器和原生输入，验收返营休息或远舟交谈，并核对游戏导出的完整恢复数据。计时阶段关闭视频录制，只在场景模块附加只读探针。无丢批、隐藏帧、失效 GPU 查询、控制台或 GL 错误。另在未附加探针的新包实测桌面及窄屏启动、移动、旋转和恢复。保留 [计时摘要](route-budget-2026-11-22/summary.json) 与 [实跑核对](route-budget-2026-11-22/native-route-audit.json)，本机完整帧流、输入与每次导出在 `dist/route-budget-2026-11-22-*`。

启用 `TIDELANDS_ROUTE_PROFILE=1` 后用 `tools/check_night_route.mjs`、`tools/check_highland_ascent.mjs` 采集，使用 `tools/analyze_route_budget.mjs` 汇总。正常验收仍可按原方式运行。
