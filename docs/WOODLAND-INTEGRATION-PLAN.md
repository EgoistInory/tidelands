# 区域林下组接入计划 · 2026-10-26

沿已授权的里程碑优先策略，本批接入已取得CC0集合中的软质蕨类与贴地苔石。幼树保持隔离，海岸资源石不替换；不把首版散点候选整体接入。林地以现有树群形成林下簇，高地低坡及海岸内陆仅少量过渡，浅滩保持开放。地标通路、资源接近和出生区留空，世界资源ID/规则/存档不变。

低矮蕨类可穿过；装饰石最高低于既有可跨越地表细节阈值，不能凭外观新增隐形墙。新建筑会压隐藏其范围的装饰。风动与深度阴影同一时钟；32m空间块及距离渐隐约束成本。加载失败保留既有游戏画面和可用入口，资源释放幂等。

先写确定性/区域通路/低石高度/建造清空/风影和释放测试并观察RED；再实现布局、同源加载及渲染，核对源许可和12个以内的本地运行文件。四岛/夜营同位及移动、实际main加载和普通档/独立包恢复通过才交付本批；非阻断细节入待办，不扩为主体树冠重做。全量规则与打包校验单次在最终修改后运行，旧性能/主线证据保持其历史范围。完整M5/3A继续开放。
