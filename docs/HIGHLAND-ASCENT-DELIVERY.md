# 雾岬高地登高路线

山脚到远舟之间增加连续的砂砾踏径，用原坡面的起伏引导上行。露岩和低草簇沿踏径两侧聚散，上方保留交谈空地。地表材质、低草和碎石共用一个空间分布，复用已有几何和材质。把显眼的装饰留在踏径外，营地仍可按现有规则清出占地。世界高度、资源点、碰撞与存档格式保持原样。

## 画面对照

两种窗口在山脚、坡中、远舟和夜间坡道各做一对同镜头 HDR 比较，合计 16 幅。首版夜间砂砾带偏亮，两项纯沿海布景测试也因重复用了沿海批次名称而失败。最终降低砂砾反差，高地和沿海分别使用各自批次，保留底层网格和材质共享。首版原图和报告留在本地 `dist/highland-ascent-2026-11-22-review-r1`。

最终增加 175 个低矮碎石和 192 簇低草。八组同镜头的完整 HDR 绘制调用增加 5–9 次、三角面最多增加 20,720。新材质与光源均沿用原资源。高处仍有裸坡，GPU 用时、长时稳定性和真机尚待核验。
