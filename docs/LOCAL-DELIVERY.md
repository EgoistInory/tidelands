近障碍自动避让会优先寻找邻近的安全取景角度；四周树冠都挡住取景时，会寻找树冠下方的较低视线。浅滩树冠保留行走和取景净空。角色在陡坡奔跑时会缩短过远、过低的摆动脚落点，减少身体突然下沉；踩实的脚仍保持在地面。复杂转角的取景距离变化、角色动作自然度与整体品质继续验收。

本批植物与贝壳采集改用完整下蹲/跪姿和手臂伸取，近距时朝真实节点伸手，结算和回收时间保持。规则仍允许3米内采集，较远节点可能超出可见手臂；身体、背包穿插与动作自然度继续作为品质待办。

驻足挥击和受击使用完整身体动作；移动和游泳继续保持原步态。夜间提高环境底光，让背光人物、地面与营地设施更容易辨认，白昼、月光方向和火光保持原有表现。完整模型、动作、声音和设备品质继续验收。

野猪的后躯、肩背和吻部采用连通轮廓，四肢近端延伸至身体，头部附件更贴合；皮毛与蟹壳加入细颗粒、粗糙度和浅表面起伏。海岸蟹的壳缘和两侧螯更有区别，原有步态、攻击、伤害和存档继续保留。关节衔接、整体自然度和近身取景仍需品质验收。

后续品质批次已接入林地蕨丛与虫鸟环境声、随游戏时钟变化的营火、低岸湿沙明暗和粗糙度过渡。攻击和采集时躯干与空闲手参与动作，落脚仍跟随地面。角色与环境的整体自然度、材质、声音试听和性能品质继续验收。

本版沙岸增加本地沙粒颜色、法线与粗糙度贴图，在湿沙带和草地之间渐变，草地或沙地贴图加载失败时各自保留原地表。来源与许可随包附带；本版仍未通过完整M5或3A品质验收。

衣装、围巾、背包和营地帐篷增加细织纹与浅表面起伏，使布料在同一光照下更有层次。角色轮廓、脸部细节、营地与植被的衔接仍需继续改善。

旅人和岛民的头身、脸部与发型已调整为更成熟的轮廓，衣袖、腰带和行装背带更贴合身体。模型、人物辨识度和动作的整体自然度继续验收，这些变化不代表最终品质已经完成。

树木增加渐细的弯曲主干、根颈与分叉枝组，使枝干和树冠更连贯。林地、岸线与风动叶片继续使用本地素材；不同树种、坡地接地和树林整体自然度仍在品质验收中。

归航灯塔增加圆润塔身、石质基脚、拱门与窄窗、环廊护栏、带框玻璃灯室和瓦顶。修复后灯室中央发光并转动光束；地标与海岸整体氛围、建筑接地和夜景自然度仍在品质验收中。

转动光束的轮廓和远端现在逐渐淡出，减少夜景中的硬边三角面片感；这是轻量外壳近似，完整体积光照仍未实现。野猪与蟹的腿增加可弯曲关节，支撑脚保持世界位置、摆腿跨步，转向提前抬脚，停止后逐脚回到站姿。AI速度、碰撞和伤害规则保持；全脚掌接触、整体动作和模型自然度继续验收。

营火、帐篷和工作台占地附近的装饰草丛会避让，减少草叶穿入帐篷地板或家具。载入其他存档后，原位置的草丛随建筑变化恢复；地面起伏与建筑接地的整体自然度继续验收。

启动时会显示准备进度，分帧处理本地地表贴图，再开放旅程入口。有可恢复的本地存档时显示“继续旅程”，刚开始就保存的进度也可以继续；新游戏或无法读取旧档时提供“开始旅程”。缺少地表素材时显示备用提示并可继续；画面准备出错或准备期间离开后恢复时，可以重新加载。准备成本仍存在，完整性能品质继续验收。

解压整个 `tidelands-local` 文件夹。需要 Python 3，以及支持 WebGL 2 的现代浏览器。

在解压目录打开终端，运行：

```sh
python3 serve.py
```

打开终端显示的 `http://127.0.0.1:4190`。端口已占用时运行 `python3 serve.py --port 4191`，打开对应地址。按 Ctrl+C 停止服务。不能直接双击 HTML：游戏模块与贴图需要本地 HTTP 服务。

Three.js、贴图及来源记录全部随包附带，无需 npm 安装或联网账户。服务只监听本机回环地址。

## 操作与旅程

WASD/方向键移动，Shift 奔跑，拖动场景转向及俯仰，滚轮缩放。E 交互，空格攻击，B 背包，C 制作，M 地图，Esc 暂停，1–6 快捷操作。手机尺寸界面使用左下摇杆、场景拖动、交互和攻击按钮。

连续按键或按住摇杆时，自动避障转镜不会改变当前移动方向；松开后重新移动会按照当前视角定向，手动拖动镜头仍可转向。

攻击会先短暂蓄势，在挥击中段判定面前近处的敌人并显示结果。先朝目标移动以转身，再按空格或点攻击；身后、正侧面或距离太远的目标不会命中。徒手、石斧、晶石剑的距离逐步增加，刃部在更低的位置挥动。打击前暂停、交互或切换装备会取消本次攻击；恢复后可以重新攻击。判定仍是游戏范围与方向规则，完整装备碰撞和不同高度目标的自然接触继续验收。

采集树木、植物和贝壳需要走到资源中心约3米以内，石料和晶石则靠近表面约1.2米；提示出现后按 E 或点采集按钮。交谈和营地互动仍保持原有距离。角色会转向资源：采植物和贝壳时蹲身徒手，采树木、石料和晶石时会使用已拥有的石斧；没有石斧时徒手采集。采集结束后恢复原来选中的装备，在动作中段获得资源、播放采集音效并显示数量。此时暂停、切换装备或攻击会取消未完成的采集；走出范围不会获得资源。游泳时请先靠岸再采集。不同资源的具体表面接触和完整自然动作仍在品质验收中。

从海岸的阿岚领取任务，采集木材与石料制作石斧，建营火后寻找林地的林栖。可以游泳跨岛，点击地图设置导航。击败野兽、前往雾岬找远舟，准备12木材、8石料和3晶石修复归航灯塔。主线完成后仍可自由探索。

暂停菜单可保存、导出/导入JSON以及开始新旅程。默认每8秒自动保存；存档属于当前浏览器与地址。切换端口、浏览器或清除网站数据前，先导出备份，到新地址再导入。开始新旅程会覆盖当前存档，确认前可先导出。

每个存档最多保留500座建筑。达到上限时建造提示会说明原因，再次确认不会扣除材料；已有500座建筑的进度仍可保存和继续。

石料和晶石现在会阻挡角色穿过实体，可走到表面附近按 E 采集；数量和恢复时间保持。耗尽后不再挡路。旧存档如站在矿物内部，可向外走出，不会被读档自动传送。避障保持手动镜头方向，并优先使用已有安全侧；部分物理转镜和角色/生物接触仍属M5品质待办。

四岛地表采用不同的草地与沙岸色调，林地有低矮地表斑块，高地坡顶与陡坡显露岩质；沿水线散布可直接走过的低矮卵石。岩面复用已有本地石料贴图，夜间提高近景环境光以便辨认路径。地形和存档格式保持；原有节点保留，追加林带节点。植被的程序化重复、岩石接地和整体自然度继续进入品质验收。

人物和活着的生物现在会阻挡彼此穿过；追击会在身体接触距离停下，附近原本重叠的生物逐步分开，旧档人物可走出重叠位置。野猪体型较大，近身攻击范围相应补偿；命中方向、伤害、奖励和冷却保持。建造位置附近有活着的野兽时会拒绝并说明原因，清理后可继续建造。完整动作、声音及复杂地形接触仍在品质验收中。

## 来源与验证

`vendor/THREE-LICENSE` 保留 Three.js 许可证；`assets` 下的 manifest 保留地表/石料素材来源与许可记录。`delivery-manifest.json` 记录本包文件大小与SHA-256，可检查解压内容是否完整。

M4 已通过正常从零主线及独立解压功能回归。后续 M5 版本的完整品质回归、实体手机/多点触控、GPU和全场景长期性能仍待验收；人物/生物材质及动作、近障碍镜头突转/遮挡和声音试听仍有品质待办。非阻断细节继续推进，功能可以先行游玩。


人物外套、袖子、裤腿和背包采用更连续的衣装轮廓；树根、矿物、营地与附近角色增加柔和接触暗部。已有悬脚或滑步仍需后续改善。敌人近身预警按当前视角左右定位，随距离渐弱；成功与菜单提示保持居中。缺少立体声定位支持时保留居中预警，声音开关与暂停规则继续生效。这些改动仍属于M5品质阶段，不代表完整3A目标完成。

采集声按木材、矿物与低物拾取区分；徒手、斧和剑的挥动声不同，命中蟹壳与野猪使用不同频段，玩家受伤有独立低频提示。音效仍在确认结算后触发，空挥不会发出命中声；原有暂停、静音和菜单成功提示保持。声音为本地合成，最终听感与真实设备品质仍待验收。

靠近营火能听到本地合成的燃烧层，随距离减弱并随当前视角左右定位；多个营火使用最近一处的固定声源预算。暂停或关闭声音时保持安静；没有立体声定位支持时居中播放。营火休息、建筑与存档规则保持。

桌面和竖屏的生命、目标、小地图与快捷栏采用更紧凑的布局，给探索画面留出空间；任务全文、交战威胁提示和原有入口保持，竖屏地图/暂停等按钮仍有至少44像素触达范围。横屏布局与独立地图弹窗继续可用。

各岛内陆增加不同方向的山肩与谷地，地面、资源高度和移动使用同一地形。岸线、出生区与任务地标附近保留原地面；旧资源身份及存档格式保持。高坡动作与整体美术仍在M5验收中。

营火使用交错圆木、灰烬和不规则围石，帐篷布面有下垂与缝边，工作台木件增加倒角和交叉支撑。三类营地设施使用有限的本地木/石/炭表面，建造与预览继续沿用原有规则。整体材质、人物自然度和场地净空仍属于M5品质待办。

建造需要避开树干与矿石的完整占地区域；刚采集的位置仍会恢复资源，也需要留空。旧营地保持原位置，与设施重叠的树木矿石暂不显现或阻挡行走；营地、背包和资源恢复记录继续保留。

林地与部分内陆树下增加本地蕨类和可直接走过的低矮苔石，保留地标接近通路与资源净空。蕨叶随风轻动，远处渐隐；建造营地时周围装饰会让出空间。素材与CC0来源说明随包附带；部分林下素材未载入时仍可继续游戏。主体树林、整体构图和完整性能仍在M5品质验收中。

旅人与三名岛民的袖裤增加连续布面外层，减少紧贴肌肉的衣装轮廓。布面跟随各自的手臂和腿部骨骼，保留原有头手、外套、工具与动作；身体接触、衣物交叠和完整自然度继续进入品质验收。
