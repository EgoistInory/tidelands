# 潮生群岛：本地里程碑版本

M1–M4 功能和本地交付里程碑已完成，包含四岛探索、采集制作、营地建造、岛民任务、装备成长、战斗、昼夜和本地存档。本包接入后续 M5 镜头碰撞、天空/海天衔接、生物及角色衣装/装备、成功音效反馈、附近敌人生命/距离提示、罗盘方向和主线完成后岛民对话改进，以及岛民待机/近距交谈朝向、攻击采集姿势衔接、攻击提示去重、地表地域色调保留和攻击判定/命中声随挥击中段提交，仍是品质阶段检查点；M5 整体验收和完整3A目标尚未完成。

## 运行

本次品质检查点还包含采集资源/音效随伸手中段提交、近岸起伏海浪与风声叠加，以及水线以上的低矮沙草斑块。声音开关与暂停共同控制环境声；完整声场和音色试听仍待验收。此版改善导入存档和开始新旅程时的切换响应，并在切换后重置生物的受击与死亡过渡。

后续品质批次已接入林地蕨丛与虫鸟环境声、随游戏时钟变化的营火、低岸湿沙明暗和粗糙度过渡。攻击和采集时躯干与空闲手参与动作，落脚仍跟随地面。角色与环境的整体自然度、材质、声音试听和性能品质继续验收。

本版沙岸增加本地沙粒颜色、法线与粗糙度贴图，在湿沙带和草地之间渐变，草地或沙地贴图加载失败时各自保留原地表。来源与许可随包附带；本版仍未通过完整M5或3A品质验收。

衣装、围巾、背包和营地帐篷增加细织纹与浅表面起伏，使布料在同一光照下更有层次。角色轮廓、脸部细节、营地与植被的衔接仍需继续改善。

营火、帐篷和工作台占地附近的装饰草丛会避让，减少草叶穿入帐篷地板或家具。载入其他存档后，原位置的草丛随建筑变化恢复；地面起伏与建筑接地的整体自然度继续验收。

启动时会显示准备进度，分帧处理本地地表贴图，再开放旅程入口。有可恢复的本地存档时显示“继续旅程”，刚开始就保存的进度也可以继续；新游戏或无法读取旧档时提供“开始旅程”。缺少地表素材时显示备用提示并可继续；画面准备出错或准备期间离开后恢复时，可以重新加载。准备成本仍存在，完整性能品质继续验收。

解压整个 `tidelands-local` 文件夹。需要 Python 3，以及支持 WebGL 2 的现代浏览器。

在解压目录打开终端，运行：

```sh
python3 serve.py
```

打开终端显示的 `http://127.0.0.1:4190`。端口已占用时运行 `python3 serve.py --port 4191`，打开对应地址。按 Ctrl+C 停止服务。不能直接双击 HTML：游戏模块与贴图需要本地 HTTP 服务。

Three.js、贴图及来源记录全部随包附带，无需 npm 安装或联网账户。服务只监听本机回环地址。

## 操作与旅程

WASD/方向键移动，Shift 奔跑，拖动场景转向及俯仰，滚轮缩放。E 交互，空格攻击，B 背包，C 制作，M 地图，Esc 暂停，1–6 快捷操作。手机尺寸界面使用左下摇杆、场景拖动、交互和攻击按钮。

攻击会先短暂蓄势，在挥击中段判定面前近处的敌人并显示结果。先朝目标移动以转身，再按空格或点攻击；身后、正侧面或距离太远的目标不会命中。徒手、石斧、晶石剑的距离逐步增加，刃部在更低的位置挥动。打击前暂停、交互或切换装备会取消本次攻击；恢复后可以重新攻击。判定仍是游戏范围与方向规则，完整装备碰撞和不同高度目标的自然接触继续验收。

采集需要走到资源中心约3米以内，提示出现后按 E 或点采集按钮；交谈和营地互动仍保持原有距离。角色会转向资源：采植物和贝壳时蹲身徒手，采树木、石料和晶石时会使用已拥有的石斧；没有石斧时徒手采集。采集结束后恢复原来选中的装备，在动作中段获得资源、播放采集音效并显示数量。此时暂停、切换装备或攻击会取消未完成的采集；走出范围不会获得资源。游泳时请先靠岸再采集。不同资源的具体表面接触和完整自然动作仍在品质验收中。

从海岸的阿岚领取任务，采集木材与石料制作石斧，建营火后寻找林地的林栖。可以游泳跨岛，点击地图设置导航。击败野兽、前往雾岬找远舟，准备12木材、8石料和3晶石修复归航灯塔。主线完成后仍可自由探索。

暂停菜单可保存、导出/导入JSON以及开始新旅程。默认每8秒自动保存；存档属于当前浏览器与地址。切换端口、浏览器或清除网站数据前，先导出备份，到新地址再导入。开始新旅程会覆盖当前存档，确认前可先导出。

M4 已通过正常从零主线及独立解压功能回归。后续 M5 版本的完整品质回归、实体手机/多点触控、GPU和全场景长期性能仍待验收；人物/生物材质及动作、近障碍镜头突转/遮挡和声音试听仍有品质待办。非阻断细节继续推进，功能可以先行游玩。
