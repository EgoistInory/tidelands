# 晴阴、昼夜与海天协调批次

依据用户已授权的M5逐批推进和无人值守续做，继续既有天空、太阳、环境光、雾及海水呈现。只读定位：当前天空随昼夜变色，但云覆盖固定；光照与雾距不响应天气，海水雾距只在构造时记录。此次采用游戏time确定性、跨多个游戏日平滑变化的晴阴参数；不改存档、地形或玩法，不新增素材、依赖和外部服务。

范围：同一cloudiness驱动云覆盖/颜色、直射与环境光、陆地雾距及海水反射/雾距。保留午夜可辨性，海水高光随直射减弱；暂停或读档回到相同time应恢复相同呈现。沿用原云层、水面和照明对象，只更新既有数值与少量uniform。第一批不添加雨粒子或假装已完成完整天气；风浪/植被响应、雨雾声音和实际试听独立继续。

先保存240晴日、720过渡、1200阴日和1440阴夜的同位真实WebGL基线，再测试确定性/范围/平滑边界、生产天空/光照/海水接线和保存状态保持。接入后取相同时刻/地点桌面与390截图及10秒运动，核对资源计数/控制台；当前源单页动态样本与普通独立包首路径另验。初始着色成本和短样本不等于最终GPU/长期显存或实体设备质量。

验收流程：隔离生产场景 → 可见晴阴/昼夜按钮 → 天空、陆地与海面共同变化且不中断渲染；普通新档 → 采集/首NPC → 保存刷新保持。M1–M4保留，M5五项和完整3A目标仍按完整证据审计。
