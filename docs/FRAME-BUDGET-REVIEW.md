# 同画布帧预算有限验收

2026-10-17；源码候选，未交付新包。完整M5/3A仍未完成。

此前桌面动态采样P95达33.4ms，但画布是2880×1392，旧生态600秒样本为1920×928。两者不能直接判断接地代码回归。本轮以同一QA页面、固定1/60步长和同一五场景，对旧d672997包与cf786ca接地候选分别采集1/1.5倍画布；每场景40帧预热、60次真实GPU查询，终点/时间/命中逐字段相同。两来源在2880×1620都出现17–21ms左右GPU P95和33ms帧间隔，降为1920×1080后，接地候选GPU P95为9.46–13.24ms。高像素填充负载是此实验的主要可复现瓶颈，接地新增CPU工作仍存在，不能据此说开销为零。旧ratio1样本与Node测试部分重叠，明确不当作严格CPU/rAF对照。

`WorldView.resize`将绘制面积限制在1920×1080像素，并尊重实际DPR与原1.5倍上限。移动到小窗口会恢复允许的像素比例，摄影机比例/CSS画布保持；没有关闭实体、地形、阴影或音效。高分屏内部绘制锐度有取舍，不称原生高DPI/4K品质。新回归先在旧版发现2880×1620分配超标，再验证1080p上限、DPR2手机585×1266、缩小恢复和DPR1不超采样。16针对性/233全量、scene语法通过。

最终生产`quality-gpu.html?full=1`桌面1920×1080实际画布1920×1080，五场景GPU P95为9.4841–13.3325ms；390×844仿真实际DPR1/画布390×844，为3.9143–8.504ms。每场景60真实GPU查询，无hidden/disjoint/console，最终两张图已实际查看。当前移动仿真DPR是1，不能把它写成1.5DPR或实体手机；DPR2的比例恢复只有单元验证。

最终`quality-endurance.html`桌面实际画布1920×928（诊断面板占去高度），60.01494秒3590帧、移动91%、12命中/62伤害/零复活、脚步调度完整，P95 18.1ms。最大116.64ms、两次>50ms均保留；短样本不能证明无尖峰、长期稳定或完整主线性能。没有操作普通存档、实际试听或测VRAM。

复核：`python3 tools/prepare_frame_budget_baseline.py`从校验过的旧ZIP及cf786ca提交构造两套忽略目录；固定步长页面可在`/dist/frame-budget-baseline/tests/frame-budget-review.html?ratio=1.5`与`/dist/frame-budget-before/tests/frame-budget-review.html?ratio=1.5`对照，ratio也可为1。`python3 tools/verify_frame_budget.py`核对数据/代码/图片SHA、分辨率、查询数、游戏终点和测试记录。旧接地/长时/生态GPU审计按各自来源保留，不重新标为本版来源。
