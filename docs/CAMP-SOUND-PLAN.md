# 营地昼夜的空间声连续性

当前生产营火已有动态火焰/近景暖光与休息规则，GameAudio只接玩家、时间、地面与足落，没有建筑输入；站在燃烧营火旁仍只有风/海浪/生态声。此为探索到营地的主要环境反馈缺口，本组补上与实际营火距离/视角一致的本地燃烧层，不回单频段或人物关节微调。

每个GameAudio只建一个共享营火声源和小型本地合成循环，选择最近有效营火、沿已有方向/距离衰减，移动视角连续平滑；多营火不堆叠声源，帐篷/工作台不冒充火。跟随master暂停/静音，释放/初始化失败完整清理；未增加下载或付费服务。另一方案为每火独立声源，远景多建筑会无谓扩大预算，当前不采用。规则/画面/存档保持。

验证：近远/无火/换档/视角/预算与失败恢复测试；原生双声道离线PCM确认左右/衰减/静音；真实main的营地开始、休息、暂停/继续与建筑输入核对，声明fixture边界。最终听感/设备和完整3A仍未验，不因新增一层声音勾完M5。
