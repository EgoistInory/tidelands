# 雾岬转身落脚与脚步声

远舟在陡坡上原地转身时，摆动脚有时够不到已算好的落脚位置。骨盆校正现在也考虑原地换脚中的目标，使脚能沿设定的短弧落下。复用当前的骨骼约束与双脚支撑，移动坐标仍由原游戏规则决定。雾岬砂砾路和露岩共用地形材质的空间分布来选择脚步声，沿用现有的合成声音缓存和实际落脚事件。

## 坡面姿势对照

用游戏实际骨架和三名岛民的所在坡面，以 60 Hz 录制 480 帧。180° 转身固定为两秒，前后两版使用同样的输入。远舟摆动脚最大离地从 45.6 降至 11.9 厘米，摆动中的目标误差从 58.8 降至 2.5 厘米。控制试验仍测得约 5 厘米的最大单脚误差，发生在旧支撑切换到新一步的起始帧，留作细节待办。林栖和阿岚同一转身条件下，最大摆动离地分别从 20.9 和 15.5 降到约 11.9 厘米。
