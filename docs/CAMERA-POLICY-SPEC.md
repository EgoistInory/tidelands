# 镜头策略重设计候选

依据当前3个完整实路输入：原相机点均在全部实体盒外，但移动后的主体视线被截短。旧unobstructedCamera要求6米取景距离，转到其他轨道；smoothCamera重新执行该全局搜索，在输入视线已受阻时直接返回远侧，单帧移动20.57/7.30/6.39米。视线遮挡、镜头实体安全和构图偏好被合并成一个硬性轨道选择，这是本轮的根因假设，已有数值复现支持。

候选将三个职责分开：镜头点沿相连的无实体路径有界移动；主体被遮挡时对前景静态物体使用局部可逆的屏幕门淡出；主体构图保持现有第三人称取景，手动yaw/pitch不改。不会把6米偏好当成必须立即换到另一侧的硬约束。旧camera函数及失败证据保留。按既有无人值守授权先做可恢复QA候选，未通过实景/物理/构图不得推广生产。

实体控制器只检查相机本身的点/运动线段、地面净空和主体空间，按角速度/世界位移预算向目标或固定绕行角点推进。视线遮挡由独立返回值报告。淡出只作用于静态前景可见材质，保留阴影与游戏身体；共享材质只安装一次、统一相机uniform更新，不拷贝素材或添加绘制pass。角色、地表、水和界面不淡出。出现不可解的实体初始状态仅作为恢复/启动例外明确记录，普通输入不得瞬移相机。

验收包括3个精确实路输入的实体安全/角位移、单墙绕行与输入不变、初始盒内恢复及帧率差异、材质回调与共享资源所有权，再进行昼夜/1280及390声明同镜头画面。仍需原生短路证据及包交付才接入生产；本候选阶段不重跑刚完成的两个十分钟旅程，不微调旧平滑阈值或单模型。
