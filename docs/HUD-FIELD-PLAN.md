# 探索与营地的可见视野

当前生产HUD在桌面使用较大的标题、面板和84像素快捷栏；390竖屏目标从160像素处开始，完整卡片继续盖住近景。此前实景的主体/环境质量问题仍保留，但构图也需要给可玩场景更充分的空间。本组只收敛探索HUD密度，不掩盖模型/环境缺口。

沿既有玻璃、金色目标与红绿生命体力设计，缩小桌面信息块/快捷栏；竖屏压紧顶部生命/目标和小地图，保留完整文字、敌人提示、44像素按钮及独立地图弹窗。横屏保持既有布局。只改CSS，不改游戏状态、画面镜头或交互入口，不新增折叠状态/功能。另一方案自动隐藏目标会影响任务可发现性，本次不采用。

先同源保存桌面/竖屏目标与敌人画面、矩形与文本溢出，再同位复核。实际检查地图/背包/制作/暂停返回及窄屏控件；不为CSS重跑310项规则/旧GPU/600秒。M5整体和完整3A仍未验，样式有限组通过后收口，继续主要主体与环境差距。
