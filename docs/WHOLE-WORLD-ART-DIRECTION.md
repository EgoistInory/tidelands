# 整场美术与全身动作收口方向

2026-10-18，起点 cdb4e93。当前交付仍是 2d922da8，完整 M5 和 3A 未完成。

本轮实际查看 docs/concept.png 和 docs/beacon-footing-normal-world.jpg。概念图只说明风格；普通画面是现有实现，二者天气、镜头和地形不同，不能作为同条件优化前后对比。

概念图的主要特征是清楚的前中远景、成组的岩壁和植被、带方向的树冠体量、角色完整衣装轮廓。当前普通画面仍有空旷而均匀的地面、重复圆冠与圆石、细长树干、关节分段明显的人物；增加局部纹理和单脚支撑没有消除整体程序化感。已有十分钟、GPU、导出恢复属于工程证据，不能据此提高美术评价。

## 下一组实现边界

采用现有概念中的温暖海岛风格，保留天气差异，不靠全局增亮或饱和度滤镜冒充资产升级。不增加新岛、任务、建筑类型或付费素材。当前运行版与普通备份保持可用。

1. **环境整体体量先行**：沿现有四岛既有资源位置统一树冠/树干比例、岩石大块面和低矮地被的成组层次；避免逐棵加微小装饰。优先改共享生成器与既有材质，保留采集 ID、规则占地和可达性，新增外轮廓须同步核对镜头/碰撞。以海岸和林地整场构图为第一轮实现对象，再核对高地/浅滩/营地。
2. **人物和两类生物成组收口**：保留现有骨架和支撑系统，集中处理整体比例、躯干到四肢的连接以及转向/起停/攻击时的躯干重心；同时检查玩家、三名 NPC、野猪和蟹。不再单独循环修改脸、袖口或蹄尖。
3. **合并验收一次**：主要整场差距修复后再冻结一次新包，对该来源做必要回归与长时/恢复。每个局部试验不重新从首树打包和重复主线。

## 可复现的整场对照入口

新增 tests/whole-world-art-review.html：复用生产 WorldView、movePlayer、tick 和跟随镜头。五个声明位置分别检查正午、黄昏、午夜；180 帧按钮包含直行、90 度输入转向，记录位置/镜头/生命/实际 rAF。没有存档读写、自动免伤、模型替换或检视镜头绕过生产避障；营地三建筑与任务6为明确 fixture。固定 1/60 模拟步长并不证明真实时间性能。

入口用于同位整场对照和发现遮挡，不能单凭 DOM 数值宣称自然动作、四岛美术、真实手机或完整主线通过。四岛/营地昼夜/390基线及来源SHA已保存，见 ENVIRONMENT-MASS-REVIEW.md。石料切面/表面主色和四类树冠明暗有限组已实现，但大地形锥形轮廓、树形和角色整体差距仍未收口；保留失败/遮挡画面，非阻断细节记录后继续整体批次。

## 完成条件

同位昼夜桌面和390画面中，玩家和主要行动空间可辨，树冠/岩石/地被形成有差异的成组体量；移动和转向连续画面不因新外轮廓新增遮挡跳变。人物与两类生物另需全身连续动作审查。两组均实际通过才能评估 M5 对应项目；仍保留混音中心3.01dB差、100ms场景切换尖峰、试听及真机待办。没有承诺本轮已经满足以上条件。
