# M5 岸线材质批次：先取得当前基线

当前地表只按高度混合草色/沙色，没有水边湿沙的深浅与粗糙度变化。海面中心高度 .12 米、两组波形各 .10 米，地表网格步长 2.5 米；不能把顶点涂色的明显条带当作最终湿沙细节。

下一次生产修改使用已有 groundPosition/groundSlope 在片元阶段形成窄湿润带，低岸适度变暗并降低粗糙度，高岸/草地/陡岩保持。首批采用静态潮痕，无额外纹理或付费服务；不复制草地纹理充当砂砾，不改变地形、世界种子/对象ID、游戏规则和存档。

先用 tests/shore-surface.html 确定四岛实际低岸位置，保存正午/午夜、桌面/390窄屏的原材质基线、控制台和渲染计数；相同脚本用于修改后对照。近景镜头为材质审查专用，不算主线或全场镜头验收。随后实现、测试加载回退不受影响、实际着色器编译、有限运动/交付。当前仅诊断准备，生产尚未改、品质尚未通过。
