# 林地夜间遭遇的攻击方向提示

晶石旁的夜间遭遇里，交互光圈与潮蟹的抬钳动作同时进入画面。最近一个正在蓄力的敌人现在会在坡面上显示琥珀色弧线，指出该次攻击锁定的方向。弧线随真实蓄力出现，出招或取消就消失。期间隐藏普通地面交互圈，交互按钮仍可使用。

所有敌人复用一条程序网格，顶点贴合现有坡面。攻击规则沿用原有时钟和锁定方向，弧线、抬钳、空间提示声由同一次蓄力驱动。只有出现预警时才绘制这段网格。
