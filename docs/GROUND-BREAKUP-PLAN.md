# 四岛地表尺度候选

实际营地/高地画面仍有大片均匀底色；目前草地每2米重复同一贴图，区域层仅在2.5米地形顶点插值，缺少连续的中尺度风化边界。此轮选择整场材质尺度对照，避免再迭代单树/单肢或只调灯色。

先在tests隔离着色器内叠加20米左右连续干湿斑、双方向草纹去重复及岩层噪声边界，不改生产代码、资源、地形、实例、灯光、普通存档或新依赖。保持区域色盘与原normal/roughness。另一方案新增世界装饰几何会提高实例与碰撞维护成本；新素材此前已有风格和开销失败，本轮不重复。

流程：固定同位/相机/时间，四岛旧新各一图；有效390午夜/营地及180帧生产移动检查运动。读取实际shader编译/GL/console和渲染统计。若主要差距未改善，保留拒用候选并收口；若有明确改善，才将已审查算法接生产并补针对性/全量、独立包恢复证据。无论结果均不称M5/完整3A完成，不重复单色强度微调。
