# 琥珀浅滩夜间阴影开销

四岛连续实走中，桌面浅滩路段 62 次 GPU 查询有 4 次超过 20 ms，集中在登陆和沙丘附近。使用原路线上记录的三个镜位、时钟与邻近检查点，从独立解包版重建固定场景。每种测量方式各取 24 个 GPU 样本。单道查询受前后绘制和 GPU 调度影响，完整四次绘制另行计时。

保持同一场景，轮流正常重绘和复用已经生成的太阳阴影，三处完整帧中位数各少约 0.66–0.96 ms。这为优化夜里的阴影更新提供了依据。现在太阳照明和水面太阳高光随暮色淡出，太阳贡献归零时停止更新太阳阴影贴图，天亮时恢复重绘。月光、环境光、近地接触阴影和营火继续照亮人物与地面。太阳使用原来的资源与着色器。
